# Sistema-Experto-O-Dimm
Proyecto de sistema experto que adivina el juego que estas pensando. Para la materia SEMINARIO DE SOLUCION DE PROBLEMAS DE SISTEMAS BASADOS EN CONOCIMIENTO

## ¿Como Jugar?
** Version por hechos de PyKnow **
1. Descarga Juego_PyKnow.py y correlo en tu IDE favorito

** Version por arbol de ID3 **
1. Descarga los archivos .pkl
2. Descarga el archivo Juego.py
3. Junta los 3 archivos en una sola carpeta
4. Corre Juego.Py en tu IDE favorito

## Sistemas expertos
Los dos archivos .py que dicen sistema experto, es exactamente lo mismo, pero uno genera el archivo Juego_PyKnow.py
de manera automatica y el otro genera los .pkl. Para ambos necesitaras games_characters.csv, ya que es el dataset de los juegos


### Extra
El archivo reglas_juegos.txt, son todos los juegos que puede adivina el juego, descargalo si quieres probar el juego
